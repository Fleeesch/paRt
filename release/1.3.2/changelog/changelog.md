**1.3.2 - Changelog**
- included launcher script for manually setting up paRt Theme Adjuster as the default Theme Adjuster
- changed all overlay modes to normal for better drawing performance
- Send Slots: implemented recently introduced target track color
- Inserts: updated parameter and send inserts design to be more distinguishable
- TCP: added option to show FX inserts in an extra block
- TCP: added optional full-width meter display for collapsed tracks
- MCP: increased vertical volume readout size
- volume readout text formatting is now identical on all tracks
- removed OS specific workarounds (not needed anymore according to Reaper V7.70 font formatting changes)
- stricter inserts visibility logic
- reworked Input button assets
- various minor color tweaks
- Items: fixed barely visible transient threshold lines
- Theme Adjuster: more reliable fallback for default parameter values
- Theme Adjuster: code cleanup (fixed typos, extended comments, removal of deprecated features)
- Theme Adjuster: Custom tab is only visible for theme files marked as unpacked or modded
- Theme Adjuster: show a little info message if a new version of paRt is available (one-time online check on Theme Adjuster launch until Reaper restarts again)
